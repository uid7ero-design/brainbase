# Add and link evidence

## Purpose

Record proof — photos, documents, statements, measurements, system records —
and connect it to the records it supports.

## When to use this

- When capturing what happened: incidents, investigations.
- What was checked: inspections, audits.
- What was found: findings.
- What was done to fix it: actions.

## Who can do this

Users with **manager** access or higher.

## Before you start

- Store the original file in your normal records system first.
- **Assurance has no file upload.** You record where the original is held.

## Steps

**Add new evidence to a record** (the usual way)

1. Open the record: incident, investigation, inspection, audit, finding or
   action.
2. In its **Evidence** section select **Add evidence**.
3. Choose the **Type**, and enter a **Title**. Optionally add a
   **Description**.
4. Enter **Where the original is held**, for example a records-system
   reference or shared-drive path.
5. Check **Captured** (defaults to now), and enter **Why it is linked
   here**.
6. Select **Add evidence**.

**Record evidence without a record yet**

7. Go to **Assurance → Evidence** and select **Record evidence**. Fill in the
   same fields.

**Reuse existing evidence**

8. Open the evidence record and select **Link to a record**.
9. Choose the **Record type** — Incident, Investigation, Inspection, Audit,
   Finding or Action — then the record. Only records you can see, that are
   still open and not already linked to this evidence, are listed.
10. Optionally enter **Why it is linked**, then select **Link**.

**Remove a link**

11. In the record's **Evidence** section, or on the evidence page, select
   **Remove link**. Enter the **Reason for removal**, then confirm.

## What happens next

- The evidence gets an `EVD-…` reference. Its page lists every link, active
  and removed, and its history.
- On an action, linked evidence can satisfy **Evidence required before
  closure**, and can be chosen as **Evidence relied on** during
  verification.

## Important rules

- Removing a link never deletes the evidence. The link stays in history with
  who removed it, when and why.
- Evidence cannot be added or removed once its record is finished: a closed or
  cancelled finding or action, or a cancelled inspection or audit.
- Evidence recorded with a verification cannot be removed.
- Evidence already used on other records cannot be linked to a
  **restricted** record. Record new evidence for it instead.
- Linking evidence never closes or verifies anything.

## Common issues

| Message or problem | What to do |
|---|---|
| "This record is finished; its evidence … can no longer be changed." | Expected; the record is closed or cancelled. |
| "This evidence is already linked to that record." | No action needed. |
| The record isn't in the list | It is closed, completed or cancelled, already linked, or restricted from you. For a closed incident or completed investigation, **Add evidence** on that record still works. |
| "…already used on other records. Linking it to a restricted record…" | Record new evidence for the restricted record instead. |
| Want to link evidence to a verification | Choose it as **Evidence relied on** when recording the verification. |
| Need to attach the file | File upload is not available yet. Record where it is held. |
