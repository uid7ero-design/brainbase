# Create and run an audit

## Purpose

Review compliance against a named standard, procedure or requirement, rating
each criterion and recording recommendations.

## When to use this

For internal, contractor, site, process, facility, policy or compliance
audits — from an audit template or ad hoc.

## Who can do this

- **Manager** access or higher plans, starts, rates, completes and raises
  findings.
- Cancelling also needs manager access.

## Before you start

- For a template-based audit, an admin must have created an **active** audit
  template.
- For an ad hoc audit, know the **standard / reference** you are auditing
  against. It is required.

## Steps

**Plan**

1. Go to **Assurance → Audits** and select **Plan audit**.
2. Enter a **Title** and **Scope**: what is audited, and what is out of scope.
3. Choose a **Template**, or leave **Ad hoc (no template)**.
4. Enter the **Standard / reference**. Required for ad hoc.
5. For ad hoc, choose the **Audit type**.
6. Optionally set **Scheduled for**, **Auditor**, **Location**, **Asset** and
   **Contractor / external organisation**.
7. Select **Plan audit**.

**Run**

8. Select **Start audit**.
9. For each criterion choose a rating: **Compliant**, **Partially
   compliant**, **Non-compliant**, **Not applicable** or **Observation**.
   Add notes, especially evidence sighted. Select **Save response**.
10. Ad hoc only: under **Assess another criterion**, describe the
    requirement, choose a response type and rating, then select **Add
    criterion**.
11. Where a gap needs formal corrective work, select **Raise finding** on
    that criterion (see [work instruction 05](05-raise-and-manage-a-finding.md)).
12. For a repeat issue already managed as a finding, use **Link existing
    finding** in the **Findings** section.

**Finish**

13. Select **Complete audit**. Add a **Summary** and **Recommendations**
    (advice for improvement), then submit.

## What happens next

- The audit moves Planned → In progress → Completed.
- Recommendations appear in the audit's **Recommendations** section.
- Findings raised or linked appear under **Findings**, and count towards
  **Open audit findings** on the Dashboard.

## Important rules

- **Non-compliant** and **Partially compliant** ratings need a note
  explaining the gap.
- A rating **never** creates a finding. **Raise finding** is offered for
  Non-compliant, Partially compliant and Observation. The decision is yours.
- A warning lists non-compliant or partial criteria that have no finding
  yet.
- Raising a finding locks that criterion's rating.
- There is **no audit-to-action shortcut**. Actions are created on the
  finding.
- Completion is refused until every required criterion is rated.
- Recommendations are advice. Formal corrective work belongs in Findings →
  Actions.
- The audit keeps the exact criteria version it was planned with.
- **Cancel audit** needs a **Reason**.

## Common issues

| Message or problem | What to do |
|---|---|
| "An ad hoc audit needs the standard or reference it is audited against." | Enter **Standard / reference**. |
| "Add a note explaining the gap against the requirement." | Add notes for Non-compliant / Partially compliant. |
| "N required criteria have no response yet." | Rate the remaining criteria. |
| **Link existing finding** not shown | There are no open findings to link (not already linked), or the audit is cancelled. |
